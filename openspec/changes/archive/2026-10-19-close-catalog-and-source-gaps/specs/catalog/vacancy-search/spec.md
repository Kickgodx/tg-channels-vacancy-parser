# Spec Delta

## MODIFIED Requirements

### Requirement: Список сужается фильтрами каталога
Список вакансий MUST содержать только уникальные вакансии (без дублей дедупа), по умолчанию без архивных (см. `catalog/vacancy-retention`). Фильтры SHALL сочетаться через «и»: канал (`source_channel`, ведущий `@` отбрасывается), грейд, формат работы, любая из выбранных специализаций, дата поста от и до включительно по UTC, `has_salary`: `true` — только с рублёвой суммой (как в аналитике), `false` — только без неё. Те же фильтры MUST действовать в метриках, аналитике и экспорте.

#### Scenario: Несколько специализаций
- **WHEN** выбраны специализации `Python` и `QA`
- **THEN** в списке вакансии, у которых есть хотя бы одна из них

#### Scenario: Канал с `@`
- **WHEN** фильтр — `source_channel=@jobs`
- **THEN** список тот же, что при `source_channel=jobs`

#### Scenario: Граница периода
- **WHEN** `date_to=2026-09-30`, а пост опубликован 30 сентября в 23:59 UTC
- **THEN** вакансия входит в список

#### Scenario: Зарплата есть только в исходной валюте
- **WHEN** у вакансии A рублёвая сумма 150 000, у B зарплата 1 000 в валюте без курса, у C зарплаты нет
- **THEN** с `has_salary=true` в списке только A, с `has_salary=false` — B и C
- **AND** метрики с `has_salary=true` считают одну вакансию с зарплатой
