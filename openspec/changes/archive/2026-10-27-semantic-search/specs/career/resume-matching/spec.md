# Spec Delta

## ADDED Requirements

### Requirement: Пакетная оценка
`POST /resumes/{id}/match-batch` с 1–20 `vacancy_ids` MUST ставить одну LLM-задачу `match_batch` (202 `{job_id}`) по общему контракту LLM-задач; повторы id схлопываются. Чужое резюме — 404, больше 20 вакансий — 422. Итог по вакансиям SHALL расти в `match_batch_result`, пока задача выполняется.

#### Scenario: Слишком много вакансий
- **WHEN** в запросе 21 вакансия
- **THEN** ответ 422, задача не ставится

### Requirement: Исход оценки вакансии в пакете
Задача MUST оценивать вакансии по одной: свежая оценка пары — `skipped` со счётом, без вызова LLM; удалённая вакансия или ошибка модели — `error` (вызов возвращается в квоту); иначе — `scored` со счётом. Квота SHALL списываться за каждую оценённую вакансию; исчерпана — задача завершается с `warning` и итогом по уже обработанным.

#### Scenario: Свежая оценка не пересчитывается
- **WHEN** у пары уже есть свежая оценка 55, у двух других — нет, одна из них падает
- **THEN** итог: `scored` 1, `skipped` 1 (со счётом 55), `errors` 1; LLM вызван дважды
