# Spec Delta

## MODIFIED Requirements

### Requirement: Квота импорта списывается по текстам
Импорт MUST списывать один вызов суточной квоты пользователя (см. `platform/llm-governance`) на каждый новый текст перед обращением к модели. Пустой текст и текст, уже имеющийся в базе, SHALL NOT тратить квоту. Если ответ на текст взят из AI-кэша и модель не вызывалась, списанный вызов SHALL возвращаться.

#### Scenario: Квота на два текста
- **WHEN** импортируются один новый и один уже сохранённый текст
- **THEN** списан один вызов квоты

#### Scenario: Ответ из кэша
- **WHEN** импортируется новый текст, ответ модели на который уже есть в AI-кэше
- **THEN** вакансия сохранена, счётчик квоты пользователя не изменился
