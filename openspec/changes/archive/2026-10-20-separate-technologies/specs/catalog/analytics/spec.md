# Spec Delta

## MODIFIED Requirements

### Requirement: Метрики дашборда
Метрики MUST содержать число вакансий, число с зарплатой и без (по рублёвой сумме), число по специализациям (50 самых частых), технологиям (`technology_top`, 50 самых частых), грейдам и формату работы (пустой — `unknown`), по дням публикации и среднюю зарплату по грейдам и специализациям (25 самых частых). Дни SHALL ограничиваться 400 последними днями с вакансиями и идти по возрастанию даты.

#### Scenario: Больше 400 дней
- **WHEN** вакансии опубликованы в 401 разный день
- **THEN** в метриках 400 самых поздних дней, по возрастанию
