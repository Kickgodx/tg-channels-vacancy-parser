# Spec Delta

## Purpose

Личные пресеты фильтров списка вакансий: сохранение под именем, список и
удаление.

## ADDED Requirements

### Requirement: Пользователь ведёт свои пресеты фильтров
Пользователь MUST иметь возможность сохранить пресет (`POST /filters`, имя 1–200 символов с обрезкой пробелов и параметры) — ответ 201 с `id`, именем, параметрами и временем создания; получить свои пресеты по алфавиту имён (`GET /filters`) и удалить пресет (`DELETE /filters/{id}`, 204; несуществующий — 404). Имена SHALL NOT быть уникальными; изменить пресет нельзя. Чужие пресеты — по `identity/access-control`.

#### Scenario: Список по алфавиту
- **WHEN** пользователь сохранил пресеты «Remote Python» и «AAA»
- **THEN** список: «AAA», «Remote Python»

#### Scenario: Повторное удаление
- **WHEN** пользователь удаляет уже удалённый пресет
- **THEN** ответ 404

### Requirement: Параметры пресета — параметры запроса списка
Параметры пресета MUST проверяться как запрос списка вакансий (фильтры, страница, размер страницы, сортировка, `resume_id`); неверные — 422. Пропущенные параметры SHALL сохраняться со значениями по умолчанию и возвращаться вместе с пресетом.

#### Scenario: Пресет с одним поиском
- **WHEN** пользователь сохраняет пресет с параметрами `{"q": "python"}`
- **THEN** в ответе `q` — `python`, `page` 1, `page_size` 50, `sort_by` `post_date`, `sort_order` `desc`

#### Scenario: Неверный размер страницы
- **WHEN** параметры пресета содержат `page_size: 1000`
- **THEN** ответ 422, пресет не сохранён
