# Proposal

## Why

Baseline нашёл ошибки конфигурации, которые проходят молча: система работает,
но не так, как задумал владелец, и сама об этом не сообщает.
- Опечатка в ключе `config.yaml` (`fx.enabeld`) игнорируется: действует
  умолчание.
- Неизвестное значение `PARSE_JOB_BACKEND`, `LLM_JOB_BACKEND` или
  `HH_SYNC_JOB_BACKEND` молча включает `inprocess`. Контейнер, рассчитанный на
  RQ, выполняет задачи в процессе API.
- С каталогом `llm_models.yaml` сверяется только `ai.model`. Модель из
  `ai.fallback_models`, `ai.match_model` или `ai.cover_letter_model` вне каталога
  падает только на запросе к провайдеру, и её стоимость считается нулевой.
- `GET /health` отвечает `ok`, если файл конфигурации существует, даже когда он
  не загружается.
- `fx.default_currency_if_missing` действует только в метриках прогона. При
  записи в базу у зарплаты без валюты нет рублёвой суммы, поэтому каталог и
  аналитика расходятся с итогами прогона.

## What Changes

- **BREAKING** Неизвестный ключ в `config.yaml` — ошибка загрузки конфигурации.
  Ошибка перечисляет пути всех неизвестных ключей. Старые ключи `ai.models` и
  `ai.fallback_model` по-прежнему принимаются. Снимок конфигурации уже созданного
  прогона так не проверяется.
- **BREAKING** `*_JOB_BACKEND` принимает только `inprocess` и `rq` (без учёта
  регистра и пробелов, пусто — `inprocess`). Другое значение — ошибка старта
  процесса.
- **BREAKING** Модели `ai.fallback_models`, `ai.match_model` и
  `ai.cover_letter_model`, если заданы, должны быть в каталоге. Иначе — ошибка
  загрузки конфигурации, которая называет поле и модель.
- `GET /health`: `config_loaded` истинно, только если конфигурация загружается
  без ошибки. Иначе `status` — `degraded`, причина пишется в журнал (в ответ не
  попадает).
- При записи вакансии в базу и при пересчёте рублёвых сумм зарплата без валюты
  считается в валюте `fx.default_currency_if_missing`. Для рубля курс не нужен.
  Пустое значение настройки — валюту не подставлять.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `platform/runtime-config`: неизвестные ключи `config.yaml`, проверка
  `*_JOB_BACKEND`, смысл `config_loaded` в `/health`.
- `platform/llm-governance`: по каталогу сверяются все модели конфигурации.
- `catalog/salary-fx`: валюта по умолчанию для зарплаты без валюты при записи и
  пересчёте.

## Impact

- Код:
  - загрузка конфигурации: `tg_jobs_parser/config/loader.py`,
    `tg_jobs_parser/ai/llm_models_registry.py`;
  - настройки процесса: `backend/settings.py`;
  - `/health`: `backend/api/routes/health.py`;
  - курсы: `backend/fx/apply.py`.
- Совместимость: `config.yaml` с лишними ключами, `.env` с неверным
  `*_JOB_BACKEND` и модели вне каталога перестанут загружаться. Сейчас
  `config.yaml` проекта всем трём требованиям удовлетворяет.
- Данные: рублёвая сумма у старых вакансий с зарплатой без валюты появится после
  `POST /fx/recalculate-rub` или повторной записи вакансии. Миграции нет.
- Документация: `config.md`, README.
