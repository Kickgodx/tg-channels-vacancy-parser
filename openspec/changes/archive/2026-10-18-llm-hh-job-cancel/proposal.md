# Proposal

## Why

Прогон парсинга можно отменить (`POST /runs/{id}/cancel`, флаг `cancel_requested`,
статус `cancelled`), а остальные фоновые задачи — нет. Ручной импорт до 50 текстов
(каждый — вызов LLM) и HH sync (сотни запросов деталей к HH.ru) идут минутами;
запущенные по ошибке (не те тексты, не то окно поиска) они доходят до конца,
тратят квоту LLM и лимиты HH и держат единственный слот активного sync. Задачу
оценки или письма тоже нельзя снять из очереди.

## What Changes

- LLM-задачи (`llm_jobs`: оценка, письмо, импорт) и HH sync (`hh_sync_jobs`)
  получают отмену по образцу прогонов: новый статус `cancelled` и флаг
  `cancel_requested`, переживающий рестарт API и воркера.
- Новые эндпоинты: `POST /llm-jobs/{id}/cancel` (владелец задачи) и
  `POST /hh/sync-jobs/{id}/cancel` (админ). Отмена идемпотентна: ответ — текущее
  состояние задачи.
- Задача в очереди отменяется сразу; выполняемая — останавливается воркером в
  ближайшей точке проверки (в режимах `rq` и `inprocess` одинаково):
  - импорт — между текстами, уже разобранные тексты остаются сохранёнными;
  - HH sync — между страницами поиска и группами деталей, уже полученные
    вакансии сохраняются, очистка кэша listings пропускается;
  - оценка и письмо — ответ модели, пришедший после отмены, **отбрасывается**,
    прежняя оценка или письмо остаются.
- Зависшая задача с запрошенной отменой при recover становится `cancelled`, а не
  уходит на повтор.
- Ответы задач (`LlmJobOut`, `HhSyncJobOut`) получают `cancel_requested`; SSE и
  опрос завершаются на `cancelled`.
- UI: кнопка «Отменить» на странице «Импорт» (пока идёт импорт) и на странице
  «HH» (пока идёт sync); частичный итог отменённой задачи показывается. Для
  оценки и письма кнопки нет — только API; клиент корректно завершает ожидание
  отменённой задачи.
- Миграция: колонка `cancel_requested` в `llm_jobs` и `hh_sync_jobs`.

## Capabilities

### New Capabilities

- `sources/hh-sync`: фоновая синхронизация вакансий с HH.ru — здесь требования к
  отмене sync и к итогу отменённого sync.

### Modified Capabilities

- `sources/manual-import`: добавляются требования к отмене импорт-задачи и к
  итогу по уже обработанным текстам.
- `career/resume-matching`: добавляется отмена задачи оценки (в очереди и во
  время ответа модели).
- `career/cover-letters`: добавляется отмена задачи письма — так же, как оценки.

## Impact

- БД: миграция `031` — `cancel_requested` в `llm_jobs` и `hh_sync_jobs`.
- Backend: `llm_job_repository`, `hh_sync_job_repository`, `llm_job_service`,
  `hh_sync_job_service`, воркеры `llm_tasks` / `hh_sync_tasks`, `import_service`,
  `hh_sync_service`, `match_service`, `cover_letter_service`, роуты `llm_jobs.py`,
  `hh.py`, `schemas.py`, метрики исходов задач, ретенция завершённых задач.
- Frontend: `api/client.ts` (cancel-методы, `cancelled` как терминальный статус,
  id задачи для отмены), `types/api.ts`, `ImportPage.tsx`, `HhPage.tsx`.
- Документация: README (импорт, HH, таблица API), CLAUDE.md (раздел про
  durable-джобы: отмена теперь у всех трёх типов).
- Новых зависимостей нет.
