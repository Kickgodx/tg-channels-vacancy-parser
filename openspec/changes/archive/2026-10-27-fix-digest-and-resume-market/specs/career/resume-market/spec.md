# Spec Delta

## MODIFIED Requirements

### Requirement: Профиль и технологии
Ответ MUST содержать `peers` — число ближайших вакансий для профиля (до 50), доли ролей и грейдов среди них (до трёх, частые первыми; грейд `unknown` не считается) и технологии, которые есть хотя бы у 10% из них (до 12), с `in_resume` — названа ли технология в резюме: её нашёл словарь «Чего не хватает» (с алиасами) или её название целым словом есть в тексте, без учёта регистра. `coverage` SHALL быть средней по ближайшим вакансиям с технологиями долей их технологий, названных в резюме; нет таких вакансий — `null`.

#### Scenario: Технология не названа
- **WHEN** у ближайших вакансий частые Python и Selenium, а в резюме есть только Python
- **THEN** у Python `in_resume` — `true`, у Selenium — `false`

#### Scenario: Вложенное название
- **WHEN** в резюме написано «Atlassian Jira», а у вакансий технология Jira
- **THEN** у Jira `in_resume` — `true`
