# Spec Delta

## ADDED Requirements

### Requirement: Текст резюме из файла
`POST /resumes/parse-file` MUST принимать тело запроса как байты файла (без multipart) не больше 5 МБ (иначе 413) и возвращать извлечённый текст, формат, число символов, признак обрезки и число страниц PDF, ничего не сохраняя. Текст длиннее лимита текста резюме (50 000) SHALL обрезаться с `truncated: true`.

#### Scenario: DOCX
- **WHEN** загружен DOCX с одним абзацем «Python developer»
- **THEN** ответ 200: текст «Python developer», формат `docx`, 16 символов, без обрезки

#### Scenario: Слишком большой файл
- **WHEN** тело запроса больше 5 МБ
- **THEN** ответ 413

### Requirement: Форматы файла резюме
Формат MUST определяться по сигнатуре, а не по имени и Content-Type: PDF — текстовый слой первых 30 страниц, DOCX — абзацы `word/document.xml`. Иной формат, PDF с паролем, PDF без текстового слоя, повреждённый DOCX и пустое тело SHALL давать 422 с причиной.

#### Scenario: Не PDF и не DOCX
- **WHEN** тело запроса — произвольный текст
- **THEN** ответ 422 с сообщением, что поддерживаются только PDF и DOCX

#### Scenario: Скан
- **WHEN** загружен PDF без текстового слоя
- **THEN** ответ 422 с советом вставить текст вручную
