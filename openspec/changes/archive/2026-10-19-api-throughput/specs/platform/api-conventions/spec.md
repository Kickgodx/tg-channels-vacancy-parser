# Spec Delta

## MODIFIED Requirements

### Requirement: Что попадает в HTTP-журнал
На запрос MUST писаться одна запись после ответа: запрос (метод, путь, клиент, заголовки, тело) и ответ (статус, длительность, заголовки, тело). Тела SHALL писаться только текстовых типов при `HTTP_LOG_BODIES` (см. `platform/runtime-config`), не длиннее `HTTP_LOG_BODY_LIMIT` (4096 байт), длинные — началом с пометкой об обрезке; поток событий и вложения — без тела. Пути `HTTP_LOG_EXCLUDE_PATHS` и CORS preflight не пишутся.

#### Scenario: Большое тело
- **WHEN** ответ длиннее лимита
- **THEN** в журнале начало тела с пометкой об обрезке

#### Scenario: Секрет в обрезанном теле
- **WHEN** тело длиннее лимита, а значение `password` начинается до границы лимита и заканчивается после неё
- **THEN** в журнале на месте значения маска, части значения нет

#### Scenario: Одна запись на запрос
- **WHEN** выполнен `GET /api/v1/vacancies`
- **THEN** HTTP-журнал получил одну запись с методом, путём, заголовками запроса, статусом и длительностью

#### Scenario: Проверка здоровья
- **WHEN** запрошен `/api/v1/health` или пришёл CORS preflight
- **THEN** HTTP-журнал записей не получает
