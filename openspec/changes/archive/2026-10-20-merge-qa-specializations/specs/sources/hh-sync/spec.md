# Spec Delta

## MODIFIED Requirements

### Requirement: Вакансия HH сохраняется без LLM
Вакансия HH MUST получать id `sha256(hh:{id})`, канал `hh`, ссылку без служебных параметров HH, дату публикации HH, текст из названия и описания без HTML, зарплату из вилки HH (`RUR` — `RUB`), формат работы (из нескольких — `remote`, затем `hybrid`, затем `office`), `vacancy_score` 100 и источник разбора `hh_api`. Специализации SHALL браться из ролей HH под каноническими именами: «Тестировщик» — `QA`, «Программист, разработчик» — `Software Engineer`, сами имена этих ролей не сохраняются; прочие роли — как есть, без ролей — пусто. Повторный sync перезаписывает поля.

#### Scenario: Детали вакансии
- **WHEN** скачаны детали вакансии с описанием в HTML, вилкой в `RUR` и форматом `REMOTE`
- **THEN** текст без тегов, валюта `RUB`, формат `remote`, источник разбора `hh_api`

#### Scenario: Ссылка со служебным параметром
- **WHEN** ссылка HH содержит `?tech_source=api`
- **THEN** у вакансии ссылка без этого параметра

#### Scenario: Вакансия без ролей
- **WHEN** у вакансии HH нет профессиональных ролей
- **THEN** её список специализаций пуст
