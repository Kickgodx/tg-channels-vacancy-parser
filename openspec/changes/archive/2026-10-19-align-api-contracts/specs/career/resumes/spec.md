# Spec Delta

## MODIFIED Requirements

### Requirement: Поля резюме ограничены по длине
Название резюме MUST быть от 1 до 200 символов после обрезки пробелов, текст — от 1 до 50 000 символов; запрос вне этих границ, в том числе название из одних пробелов, SHALL отклоняться с 422 без изменений. При изменении резюме пропущенное поле не меняется.

#### Scenario: Пустой текст
- **WHEN** пользователь создаёт резюме с пустым текстом
- **THEN** ответ 422, резюме не создаётся

#### Scenario: Название из пробелов
- **WHEN** пользователь создаёт резюме с названием `"   "` или переименовывает резюме в `"   "`
- **THEN** ответ 422, резюме не создаётся и не меняется
