# Spec Delta

## MODIFIED Requirements

### Requirement: Пользователь ведёт свои пресеты фильтров
Пользователь MUST иметь возможность сохранить пресет (`POST /filters`, имя 1–200 символов после обрезки пробелов и параметры) — ответ 201 с `id`, именем, параметрами и временем создания; получить свои пресеты по алфавиту имён (`GET /filters`) и удалить пресет (`DELETE /filters/{id}`, 204; несуществующий — 404). Имя из одних пробелов SHALL давать 422. Имена не уникальны; изменить пресет нельзя. Чужие пресеты — по `identity/access-control`.

#### Scenario: Список по алфавиту
- **WHEN** пользователь сохранил пресеты «Remote Python» и «AAA»
- **THEN** список: «AAA», «Remote Python»

#### Scenario: Повторное удаление
- **WHEN** пользователь удаляет уже удалённый пресет
- **THEN** ответ 404

#### Scenario: Имя из пробелов
- **WHEN** пользователь сохраняет пресет с именем `"   "`
- **THEN** ответ 422 `VALIDATION`, пресет не создаётся
