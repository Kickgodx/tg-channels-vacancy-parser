# Spec Delta

## ADDED Requirements

### Requirement: Общий API-ключ дополняет вход
При заданном `API_KEY` каждый запрос, требующий JWT, MUST нести заголовок `X-API-Key` с этим значением, иначе — 401 `NOT_AUTHENTICATED`, и действие не выполняется. Исключения: `/health` и `/auth/*`, кроме выдачи SSE-тикета; поток событий по одноразовому тикету ключа не требует, по `Authorization: Bearer` — требует. Ключ SHALL приниматься только из заголовка. Без `API_KEY` заголовок не нужен.

#### Scenario: Резюме без ключа
- **WHEN** задан `API_KEY`, и пользователь с действующим JWT без `X-API-Key` создаёт резюме
- **THEN** ответ 401 `NOT_AUTHENTICATED`, резюме не создано

#### Scenario: Пресеты и LLM-задачи без ключа
- **WHEN** задан `API_KEY`, и пользователь с JWT без `X-API-Key` запрашивает свои пресеты или свою LLM-задачу
- **THEN** ответ 401 `NOT_AUTHENTICATED`

#### Scenario: С ключом
- **WHEN** задан `API_KEY`, и пользователь с JWT и верным `X-API-Key` запрашивает резюме, пресеты и LLM-задачу
- **THEN** ответы как без `API_KEY`

#### Scenario: Поток событий по тикету
- **WHEN** задан `API_KEY`, пользователь получил SSE-тикет с ключом и открывает поток событий своей LLM-задачи по тикету без `X-API-Key`
- **THEN** поток открывается

#### Scenario: Ключ не задан
- **WHEN** `API_KEY` не задан
- **THEN** запросы с JWT без `X-API-Key` проходят
