# Spec Delta

## ADDED Requirements

### Requirement: Замена базы предупреждает о потере данных пользователей
`cli db import --mode replace` MUST перед подтверждением называть, сколько оценок соответствия, сопроводительных писем и LLM-задач с вакансией удалится вместе с вакансиями: в дамп они не входят. При отказе SHALL ничего не меняться. Режим `merge` данные пользователей не удаляет и подтверждения не требует.

#### Scenario: Есть данные пользователей
- **WHEN** в целевой базе 2 оценки, 1 письмо и 3 LLM-задачи с вакансией, администратор запускает импорт в `replace`
- **THEN** подтверждение называет 2 оценки, 1 письмо и 3 LLM-задачи

#### Scenario: Отказ
- **WHEN** администратор отвечает «нет» на подтверждение `replace`
- **THEN** импорт не выполняется, вакансии, оценки, письма и LLM-задачи на месте

#### Scenario: merge
- **WHEN** дамп импортируется в `merge`
- **THEN** подтверждение не запрашивается, оценки и письма остаются
