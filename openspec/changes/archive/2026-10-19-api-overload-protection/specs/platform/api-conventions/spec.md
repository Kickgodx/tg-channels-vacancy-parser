# Spec Delta

## ADDED Requirements

### Requirement: Перегруженный API отклоняет лишние запросы
Процесс API MUST обрабатывать одновременно не больше запросов, чем у него соединений с БД; остальные ждут своей очереди. Запрос, не начавший обработку за `API_QUEUE_TIMEOUT_SECONDS`, SHALL получать 503 с кодом `OVERLOADED`, `retryable: true` и заголовком `Retry-After`. `GET /health` MUST отвечать без этой очереди. SSE-стрим SHALL освобождать место, как только начался ответ.

#### Scenario: Всплеск выше пропускной способности
- **WHEN** поток запросов превышает то, что API успевает обработать
- **THEN** часть запросов получает 503 `OVERLOADED` не позже чем через `API_QUEUE_TIMEOUT_SECONDS`, остальные обслуживаются, и после спада нагрузки API сразу отвечает как обычно

#### Scenario: Проверка здоровья под нагрузкой
- **WHEN** все места обработки заняты
- **THEN** `GET /health` отвечает, не дожидаясь очереди

#### Scenario: Открытые SSE-стримы
- **WHEN** у процесса открыто больше SSE-стримов, чем мест обработки
- **THEN** обычные запросы обслуживаются без 503
