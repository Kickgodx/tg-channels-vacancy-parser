# Spec Delta

## ADDED Requirements

### Requirement: Узлы графа технологий
`GET /analytics/technology-graph` MUST брать узлами `nodes` (5–80, по умолчанию 40; вне диапазона — 422) самых частых технологий среди вакансий под фильтрами каталога без собственного фильтра по технологии. У узла SHALL быть число вакансий с технологией, доля от всех вакансий под фильтрами (`total`) и специализация, с которой технология встречается чаще всего.

#### Scenario: Фильтр по технологии не применяется
- **WHEN** запрос с `technology=Kafka`
- **THEN** узлы те же, что без этого фильтра; остальные фильтры действуют

#### Scenario: Дубли не считаются
- **WHEN** технология встречается только в дублях дедупа
- **THEN** её нет среди узлов

### Requirement: Рёбра графа технологий
Ребро — пара узлов, которая встречается вместе не меньше чем в 3 вакансиях (`min_pair_count`). У ребра MUST быть число таких вакансий и lift = `n_ab · total / (n_a · n_b)`.

#### Scenario: Пара реже порога
- **WHEN** Kafka и Python вместе в двух вакансиях
- **THEN** ребра Kafka — Python нет, оба узла есть

#### Scenario: Lift пары
- **WHEN** под фильтрами 20 вакансий, Go — в 6, Kafka — в 6, вместе — в 4
- **THEN** у ребра Go — Kafka `count` 4 и `lift` 4 · 20 / (6 · 6)

### Requirement: Порядок рёбер
Рёбра SHALL идти по убыванию lift.

#### Scenario: Самая неслучайная пара первой
- **WHEN** у пары .NET — C# lift 20, у Python — SQL — 2
- **THEN** .NET — C# идёт раньше
