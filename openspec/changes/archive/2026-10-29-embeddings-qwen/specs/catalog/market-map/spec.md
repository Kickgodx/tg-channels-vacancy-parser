# Spec Delta

## MODIFIED Requirements

### Requirement: Пересчёт по расписанию
Лидер API MUST пересчитывать карту, если её нет или она старше `ai.embeddings.map_interval_hours`; при `0` пересчёт SHALL быть только по кнопке администратора. Карту, посчитанную не текущей моделью эмбеддингов, лидер MUST пересчитывать, как только у всех уникальных вакансий есть вектор текущей модели (при любом интервале, кроме `0`). Пересчёт вручную — только администратор (403 остальным).

#### Scenario: Свежая карта
- **WHEN** карте 2 часа, интервал 24 часа
- **THEN** лидер её не пересчитывает

#### Scenario: Сменили модель
- **WHEN** карте 2 часа, она посчитана прежней моделью, каталог переиндексирован целиком
- **THEN** лидер её пересчитывает

### Requirement: Резюме на карте
`GET /market-map?resume_id=` MUST ставить своё резюме пользователя во взвешенную (обратно расстоянию) среднюю 15 ближайших к нему по эмбеддингу вакансий карты и возвращать их id и самую частую среди них нишу. Чужое резюме — 404; эмбеддинги недоступны или карта посчитана не текущей моделью — карта отдаётся без резюме с `resume_error`.

#### Scenario: Резюме тестировщика
- **WHEN** на карте ниши QA и Backend, а резюме — тестировщика
- **THEN** ближайшая к резюме вакансия — из QA

#### Scenario: Карта прежней модели
- **WHEN** карта посчитана прежней моделью, а настроена другая
- **THEN** карта отдаётся без резюме, с `resume_error`
