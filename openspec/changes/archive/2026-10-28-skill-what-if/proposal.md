# Proposal

## Why

«Чего не хватает» и «Резюме и рынок» показывают пробелы, но не отвечают на вопрос «что учить
первым»: какая недостающая технология сильнее всего расширит выбор вакансий и сколько она стоит
на рынке. Все данные для ответа уже есть — эмбеддинги резюме и вакансий, технологии каталога,
премия технологий с поправкой на грейд.

## What Changes

- `GET /resumes/{id}/what-if` (без LLM): сегмент — 200 вакансий, ближайших к резюме по эмбеддингу
  за год. Вакансия подходит, если резюме называет ≥ 70% её технологий. Для недостающих технологий
  (от 5 вакансий и 3% сегмента; многословные русские практики вроде «Написание автотестов» — не
  технологии): спрос, сколько вакансий станут подходящими, рост среднего покрытия, премия (в грейде
  сегмента, иначе по роли) и медиана зарплаты вакансий с технологией. `peer_gaps` — чтобы UI считал
  сочетания технологий без запросов.
- `technology_premiums` — премия для заданного списка технологий (общий расчёт с аналитикой).
- `resume_market_service`: общие `nearest_vacancies` и `resume_technology_check`.
- UI: панель «Что если выучить» на странице «Резюме» с отметками технологий.

## Capabilities

### New Capabilities

- `career/skill-what-if` — эффект недостающих технологий для резюме.

## Impact

Без миграции. Нужны эмбеддинги (`ai.embeddings.enabled`), иначе 503 `UPSTREAM_UNAVAILABLE`.
