# Spec Delta

## ADDED Requirements

### Requirement: Ближайшие к резюме вакансии
`GET /resumes/{id}/market` MUST строиться по уникальным вакансиям (включая архивные), опубликованным за последние 365 дней и проиндексированным текущей моделью эмбеддингов, в порядке косинусного расстояния до вектора резюме. LLM SHALL не вызываться; вектор резюме берётся из БД или считается заново, если сменился текст. Чужое резюме — 404; эмбеддинги выключены или провайдер недоступен — 503 `UPSTREAM_UNAVAILABLE`.

#### Scenario: Что не входит
- **WHEN** среди ближайших есть дубль и вакансия старше года
- **THEN** ни одна из них не входит в ближайшие, архивная вакансия входит

#### Scenario: Эмбеддинги выключены
- **WHEN** `ai.embeddings.enabled` — `false`
- **THEN** ответ 503 с кодом `UPSTREAM_UNAVAILABLE`

### Requirement: Профиль и технологии
Ответ MUST содержать `peers` — число ближайших вакансий для профиля (до 50), доли ролей и грейдов среди них (до трёх, частые первыми; грейд `unknown` не считается) и технологии, которые есть хотя бы у 10% из них (до 12), с `in_resume` — названа ли технология в тексте резюме (поиск словарём «Чего не хватает», без учёта регистра). `coverage` SHALL быть средней по ближайшим вакансиям с технологиями долей их технологий, названных в резюме; нет таких вакансий — `null`.

#### Scenario: Технология не названа
- **WHEN** у ближайших вакансий частые Python и Selenium, а в резюме есть только Python
- **THEN** у Python `in_resume` — `true`, у Selenium — `false`

### Requirement: Зарплата ближайших
Квантили (p10, p25, медиана, p75, p90 с линейной интерполяцией) MUST считаться по рублёвой зарплате до 30 ближайших вакансий с зарплатой среди 200 ближайших; `salary_count` — их число. Если таких меньше 8, квантилей SHALL не быть (`null`, `salary_count` 0).

#### Scenario: Мало зарплат
- **WHEN** у ближайших вакансий семь зарплат
- **THEN** `median` — `null`, `salary_count` — 0
