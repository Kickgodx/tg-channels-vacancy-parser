# Spec Delta

## MODIFIED Requirements

### Requirement: Топ работодателей
Аналитика работодателей MUST давать до `limit` (20, от 1 до 100) компаний по убыванию числа вакансий, при равенстве — по названию; вакансии без компании не входят. Компании SHALL сводиться по нормализованному названию (`company_key`, см. `catalog/company-profile`), название в ответе — самое частое написание. Для компании SHALL указываться число вакансий, средний `vacancy_score`, число вакансий с зарплатой и средняя зарплата в рублях.

#### Scenario: Порядок
- **WHEN** у Alpha три вакансии (одна с зарплатой 300 000 ₽), у Beta — одна, у одной вакансии компании нет
- **THEN** порядок Alpha, Beta; у Alpha 3 вакансии, с зарплатой 1, средняя 300 000

#### Scenario: Написания одной компании
- **WHEN** две вакансии «Bell Integrator» и одна «BELL INTEGRATOR»
- **THEN** в топе одна компания «Bell Integrator» с 3 вакансиями
