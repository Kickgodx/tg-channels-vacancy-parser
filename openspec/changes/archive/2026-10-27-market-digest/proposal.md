# Proposal

## Why

Аналитика отвечает на вопросы, которые пользователь сам задаёт фильтрами. Чтобы понять,
что изменилось за неделю, её приходится перебирать вручную. Нужна готовая еженедельная
сводка по базе: сколько вакансий, какие роли, зарплаты, технологии и компании выросли или
упали. И короткий текст, который можно прочитать за минуту, без выдуманных цифр.

## What Changes

- Факты недели (пн–вс, UTC, по дате поста, уникальные вакансии с архивом): объём против
  прошлой недели и среднего за 4 недели, доля с зарплатой, роли, форматы, источники и
  компании с прошлой неделей, новые компании, медианы зарплаты по грейдам (28 дней против
  28), технологии с наибольшим ростом и падением доли (неделя против 4 недель до неё).
- Текст LLM только по этим фактам (модель писем, `MARKET_DIGEST_PROMPT_VERSION`), своим
  клиентом вне суточного бюджета пользовательского LLM. Ошибка модели — обзор без текста с
  пометкой, текст ошибки провайдера наружу не отдаётся.
- Таблица `market_digests` (миграция 044), одна строка на неделю. Лидер API раз в час
  формирует обзор за прошедшую неделю, если его нет и в неделе есть вакансии
  (`digest.enabled`, `digest.llm_summary` в `config.yaml`).
- `GET /digests`, `GET /digests/{period_start}` — любому залогиненному; `POST /digests` —
  админу: обзор любой завершённой недели, `force` — пересчёт.
- UI: страница «Обзор» (`/digest`).
