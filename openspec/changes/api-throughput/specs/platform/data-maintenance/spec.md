# Spec Delta

## MODIFIED Requirements

### Requirement: Плановая очистка при старте и раз в час
При старте API и затем раз в час MUST выполняться очистка: архивирование вакансий (см. `catalog/vacancy-retention`), кэш выдачи HH и грейды HH (см. `sources/hh-sync`), а также служебные таблицы ниже. Очистку SHALL выполнять один процесс API из всех, работающих с этой базой (см. `platform/runtime-config`); если он завершился, её не позже чем через минуту берёт другой. Сбой очистки SHALL только записываться в журнал и не мешать работе API.

#### Scenario: Сбой очистки
- **WHEN** при старте очистка служебных таблиц упала
- **THEN** API стартует, в журнале предупреждение

#### Scenario: Несколько процессов API
- **WHEN** API запущен с `API_WORKERS=4`
- **THEN** очистка при старте выполнилась один раз, а не четыре

#### Scenario: Процесс-исполнитель завершился
- **WHEN** процесс, выполнявший очистку, упал, а остальные процессы API работают
- **THEN** не позже чем через минуту очистку выполняет другой процесс
