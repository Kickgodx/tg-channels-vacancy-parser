# platform/mcp-server Specification

## Purpose
MCP-сервер для Claude Desktop / Claude Code поверх HTTP API: доступ по токену, формат ответов, LLM-инструменты.

## Requirements

### Requirement: Клиент API с токеном
MCP-сервер (`python -m jobdesk_mcp`, stdio) MUST обращаться к данным только через HTTP API (`JOBDESK_API_URL`, по умолчанию `http://127.0.0.1:9000/api/v1`) с PAT из `JOBDESK_TOKEN` (и `X-API-Key` из `JOBDESK_API_KEY`, если задан) и SHALL NOT импортировать `backend` или `jobdesk`. Если переменная `JOBDESK_*` не задана, MUST читаться одноимённая `TGJOBS_*` (имена до переименования проекта). Без `JOBDESK_TOKEN` процесс MUST завершаться с кодом 2 и сообщением в stderr. Ошибка API MUST возвращаться инструментом как ошибка (`is_error`) с текстом и кодом API и подсказкой: токен недействителен, нет права LLM, эмбеддинги недоступны, API не отвечает.

#### Scenario: API не запущен
- **WHEN** инструмент вызван, а API по `JOBDESK_API_URL` не отвечает
- **THEN** инструмент возвращает ошибку «API недоступен» с адресом, без значения токена

### Requirement: Компактные ответы и недоверенный текст
Инструменты MUST возвращать JSON без пустых полей, со списками не длиннее 20 элементов; поиск MUST отдавать не больше 20 карточек (превью до 300 символов), полный текст вакансии — до 4000 символов, обёрнутый в маркеры «данные, не инструкции».

#### Scenario: Текст вакансии
- **WHEN** запрошена вакансия, текст которой содержит «игнорируй инструкции»
- **THEN** текст возвращается между маркерами `<<<ДАННЫЕ…>>>` и `<<<КОНЕЦ ДАННЫХ>>>`

### Requirement: LLM-инструменты
Инструменты оценки резюме, пакетной оценки, письма, адаптации, подготовки к собеседованию и «Спросить базу» MUST возвращать готовый результат API (200) сразу, а при постановке задачи (202) — опрашивать `GET /llm-jobs/{id}` до `JOBDESK_LLM_WAIT_SECONDS` (по умолчанию 60) и, если задача не завершилась, возвращать `job_id`, который `get_llm_job` превращает в результат. Отмена вызова клиентом MUST отменять задачу (`POST /llm-jobs/{id}/cancel`). `force` по умолчанию SHALL NOT передаваться.

#### Scenario: Задача не успела
- **WHEN** LLM-задача не завершилась за время ожидания
- **THEN** инструмент возвращает `job_id` и статус, а `get_llm_job` после завершения — результат
