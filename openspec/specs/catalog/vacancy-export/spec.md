# catalog/vacancy-export Specification

## Purpose
Выгрузка вакансий каталога в Excel по фильтрам и сортировке списка: потолок
строк, состав файла и потоковая сборка.

## Requirements

### Requirement: Экспорт каталога следует фильтрам и сортировке списка
`GET /vacancies/export.xlsx` MUST выгружать вакансии под фильтрами и сортировкой списка (см. `catalog/vacancy-search`), без пагинации — первые по сортировке, не больше `EXPORT_MAX_ROWS` (см. `parse-runs`). При обрезке ответ SHALL нести заголовок `X-Export-Truncated: <выгружено>/<всего>`; без обрезки заголовка нет.

#### Scenario: Вакансий больше потолка
- **WHEN** `EXPORT_MAX_ROWS: 2`, под фильтрами три вакансии
- **THEN** в файле две самые поздние по дате поста, заголовок `X-Export-Truncated: 2/3`

#### Scenario: Вакансий меньше потолка
- **WHEN** под фильтрами вакансий не больше `EXPORT_MAX_ROWS`
- **THEN** в файле все они, заголовка `X-Export-Truncated` нет

### Requirement: Состав файла экспорта
Файл MUST содержать лист `vacancies` — строка на вакансию, колонки по `tg_jobs_parser/exporters/excel_exporter.py`, включая исходный и очищенный текст — и лист `metrics_summary` с метриками выборки, `exported_rows` и `matching_rows`, а при обрезке — `truncated` с пояснением. Тексты SHALL записываться одной строкой, без недопустимых для Excel символов и не длиннее ячейки Excel; даты — UTC без часового пояса. Тот же формат у Excel-экспорта прогона.

#### Scenario: Управляющий символ в тексте
- **WHEN** исходный текст вакансии содержит управляющий символ `\x01`
- **THEN** в ячейке текст без него, файл открывается

#### Scenario: Сводка обрезанного экспорта
- **WHEN** выгружено 2 вакансии из 3
- **THEN** в `metrics_summary` `exported_rows` 2, `matching_rows` 3 и пояснение «обрезано до 2 из 3»

### Requirement: Экспорт собирается потоком
Экспорт MUST читать выборку одним запросом порциями и записывать строки по мере чтения, не держа все вакансии в памяти процесса.

#### Scenario: Большая выборка
- **WHEN** выгружается каталог
- **THEN** к таблице вакансий один запрос выборки, прочитанные строки не накапливаются в сессии
