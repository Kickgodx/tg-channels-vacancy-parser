# catalog/vacancy-search Specification

## Purpose
Список и карточка вакансий общего каталога: фильтры, полнотекстовый поиск,
сортировка, пагинация и проверка параметров. Фильтры списка — общие для метрик,
аналитики и экспорта.

## Requirements

### Requirement: Список сужается фильтрами каталога
Список вакансий MUST содержать только уникальные вакансии (без дублей дедупа), по умолчанию без архивных (см. `catalog/vacancy-retention`). Фильтры SHALL сочетаться через «и»: канал (`source_channel`, ведущий `@` отбрасывается), грейд, формат работы, любая из выбранных специализаций, дата поста от и до включительно по UTC, `has_salary=true` — только с указанной зарплатой. Те же фильтры MUST действовать в метриках, аналитике и экспорте.

#### Scenario: Несколько специализаций
- **WHEN** выбраны специализации `Python` и `QA`
- **THEN** в списке вакансии, у которых есть хотя бы одна из них

#### Scenario: Канал с `@`
- **WHEN** фильтр — `source_channel=@jobs`
- **THEN** список тот же, что при `source_channel=jobs`

#### Scenario: Граница периода
- **WHEN** `date_to=2026-09-30`, а пост опубликован 30 сентября в 23:59 UTC
- **THEN** вакансия входит в список

### Requirement: Полнотекстовый поиск по тексту вакансии
Параметр `q` (до 500 символов) MUST искать по очищенному тексту вакансии полнотекстовым поиском русской конфигурации: слова сравниваются по основе, поддерживается синтаксис веб-поиска (фразы в кавычках, исключение через `-`). С `q` выдача SHALL упорядочиваться сначала по релевантности, затем по выбранной сортировке.

#### Scenario: Другая форма слова
- **WHEN** пользователь ищет «разработчик», а в тексте вакансии «разработчиков»
- **THEN** вакансия найдена, вакансии без этого слова — нет

### Requirement: Сортировка списка
`sort_by` MUST принимать `post_date` (по умолчанию), `detected_salary_avg`, `detected_salary_avg_rub`, `work_format`, `detected_grade`, `salary_currency`, `vacancy_score` и `match_score` (см. `career/resume-matching`); другое значение — 422. `sort_order` — `asc` или `desc` (по умолчанию). Пустые значения SHALL идти в конце при любом направлении, равные — по `id`.

#### Scenario: Зарплата в рублях по убыванию
- **WHEN** у трёх вакансий рублёвая зарплата 300 000, пусто и 150 000, сортировка — `detected_salary_avg_rub`
- **THEN** порядок: 300 000, 150 000, без зарплаты

#### Scenario: Недопустимое поле
- **WHEN** `sort_by=raw_text`
- **THEN** ответ 422 `VALIDATION`

### Requirement: Список листается до 10 000 позиций
`page` MUST быть от 1, `page_size` — от 1 до 500 (по умолчанию 50). Страница дальше 10 000 позиций (`page × page_size`) SHALL давать 422 `VALIDATION` с советом уточнить фильтры. Ответ содержит `total` — число вакансий под фильтрами; страница за последней — пустая, с тем же `total`.

#### Scenario: Последняя доступная страница
- **WHEN** `page_size=50` и `page=200`, затем `page=201`
- **THEN** первый ответ 200, второй — 422 `VALIDATION`

#### Scenario: Страница за концом списка
- **WHEN** под фильтрами 5 вакансий, запрошена `page=10` при `page_size=2`
- **THEN** `items` пуст, `total` равен 5

### Requirement: Параметры каталога проверяются
Неверный тип или значение вне границ у фильтров, пагинации и `limit` списка, метрик, аналитики и экспорта MUST давать 422 `VALIDATION` с описанием поля, а не ошибку сервера. Пустой параметр (`date_from=`) SHALL считаться незаданным.

#### Scenario: Неверная дата
- **WHEN** запрошены метрики с `date_from=yesterday`
- **THEN** ответ 422 `VALIDATION`

#### Scenario: Пустой параметр
- **WHEN** список запрошен с `date_from=&date_to=`
- **THEN** ответ 200, фильтр по датам не применяется

### Requirement: Список отдаёт превью, карточка — полный текст
Элемент списка MUST содержать `preview` — начало очищенного текста до 120 символов, с «…» при обрезке — и не содержать `raw_text` и `cleaned_text`. `GET /vacancies/{id}` SHALL отдавать вакансию целиком, с обоими текстами; несуществующий id — 404.

#### Scenario: Длинная вакансия в списке
- **WHEN** очищенный текст вакансии длиннее 120 символов
- **THEN** в списке `preview` из 120 символов и «…», полных текстов нет; в карточке оба текста целиком

#### Scenario: Несуществующая вакансия
- **WHEN** запрошена карточка по неизвестному id
- **THEN** ответ 404
